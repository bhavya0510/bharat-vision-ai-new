# Bharat Vision AI - New Version

Bharat Vision AI platform showcasing cultural heritage art generation and exploration.

## Overview
This repository contains the standalone frontend application for Bharat Vision AI.

- **`index.html`**: Main application entry point (configured for direct browser preview and GitHub Pages deployment).
- **`Bharat Vision AI new.html`**: Source file copy.

## Live Demo / Usage
1. Open `index.html` directly in any modern web browser, or
2. Host on GitHub Pages by enabling Pages under **Settings > Pages > Branch: main**.
